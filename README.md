# Photography World

A simple photography-themed web page with an image gallery.

**Repository created:** 2021-03-05  
**Project status:** Learning project / historical snapshot  
**Earliest recorded commit (author date):** 2021-03-05

## Features and implementation

- HTML image elements and captions.
- CSS styling.
- Heading and date placeholder.

## Technologies

HTML, CSS.

## Project structure

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | Main page and user interface |
| [`style.css`](style.css) | Page styling |

## Run or explore locally

```bash
git clone https://github.com/Avenger-Sonic123/myBlog.git
cd myBlog
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The local server requires Python 3; browser-based dependencies may also require internet access.

Browse the photographs on the page.

## Current status and limitations

Images depend on remote URLs; the date placeholder has no date-setting script.
